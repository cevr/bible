# North stars

Every candidate names the north star it serves, and every rejection names the north star it would break. When two pull against each other, the ledger row says so and the decision cites a principle from `~/Developer/personal/dotfiles/principles/`. A sweep does not decide it.

| North star                 | It holds when                                                                                                                                                                                                                                                                                                                   | A candidate breaks it when                                                                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pure frames**            | Any frame renders alone from the film and a time: no state carried between frames, randomness seeded by key. So preview scrubs anywhere and export splits across pages.                                                                                                                                                         | It keeps mutable scene state, replays a timeline from zero to reach a frame, reads `Math.random` or the wall clock, or makes frame N depend on N-1.                                          |
| **Narration is the clock** | Time comes from recorded words. A scene is sized by its take; a motion is pinned to a mark. Re-recording a line moves everything tied to it.                                                                                                                                                                                    | It pins a motion or a sound to a literal second, or sizes a scene by hand where the take could size it.                                                                                      |
| **Declared once**          | A moment (a stamp lands, a cord drops) is named in one place, and the picture, the sound, the captions and the checks all read that name.                                                                                                                                                                                       | The same time is written in two places, such as a scene's `progress(…, mark + 0.9)` and `sound.ts` repeating `mark + 1.2`.                                                                   |
| **Effect-native tooling**  | Work outside the draw loop is an `Effect` or `Stream`. Resources (browser pages, the lab server, open files, API calls) live in a `Scope`. Failures are typed. Every file and API boundary (and every lab request) decodes with `Schema`.                                                                                       | It adds a bare Promise chain, an untyped `throw`, a manual cleanup, or a hand-written JSON cast at a boundary where Effect has the tool.                                                     |
| **Cheap iteration**        | Every generated asset is content-addressed by its request. A rerun does only stale work, a remix never calls a paid API, and the review loop (a stills or contact sheet) takes seconds.                                                                                                                                         | A change forces a full re-render, re-recording or regeneration it does not need, or the review loop gets slower.                                                                             |
| **Checked, not eyeballed** | A defect class a review finds once becomes a check: collisions, stale assets, unknown marks, missing sources.                                                                                                                                                                                                                   | A fix lands for one instance of a class the engine could detect.                                                                                                                             |
| **Explicit over implicit** | What matters is visible where it is written: the clock a scene reads, a seed key, a transition, a gain, an asset's hash.                                                                                                                                                                                                        | It adds a hidden default, a magic name, or behavior that depends on call order or ambient globals.                                                                                           |
| **Performant**             | Measured, not guessed: a speed claim carries a before and after on one machine (ms per frame, allocations in the draw path, render fps or lab frame time). Hot paths are data-in, data-out over caller-owned arrays (the pmndrs `math` style): no allocation per point, per stroke or per frame where a scratch value would do. | It claims a speed-up without a measured before/after, allocates per point in a per-frame loop, adds a closure or object per frame, or trades a pure frame for speed (caching across frames). |
| **Lab-first**              | Anything a review may tweak is data the lab can reach: a cue (timing, easing) or a knob (a number or a point). The lab writes it back to the scene's literal, shows motion (onion, slow, loop), compares with HEAD, and every note hands the agent the frame, the still and the nearest cue.                                    | A tweakable value stays a constant a note cannot reach, the lab keeps a second copy of a value (a sidecar), or a lab feature works only on one film.                                         |

## The draw-loop boundary

The per-frame draw path (`draw(frame)`, ink, cutout, type, camera, the kit) runs thousands of times per render and stays synchronous plain code in the pmndrs `math` style: plain arrays, functions that write into their first argument, no hidden allocation. Reach for `math` (`vec2`, `mat2d`, `math/time` easing and springs, `math/random`, `math/noise`, `math/ik`) before writing a helper it already has. **Effect-native tooling** governs everything around it: loading, narration, sound, checks, the lab server, render orchestration. A candidate that puts an Effect runtime inside the draw path is rejected on **Performant**.

## How to use them in a sweep

- A deletion that keeps every north star is the best candidate. Name the north star that makes the deleted code unnecessary.
- **Explicit** beats **declarative brevity**: shorter code that hides a clock, a seed or a time is rejected.
- **Pure frames** beats **authoring ergonomics** and **Performant**: a timeline model that needs replay to seek, or a cache carried between frames, is rejected unless it compiles to random-access time.
- **Performant** claims need a measurement: a candidate without a before/after is a question, not a finding.
- **Art direction** beats **Performant** (owner, 2026-09-27): performance stays top of mind, but never at the cost of the look. The raster (grain, pastel, shadow, vignette) is most of the frame time, and it is the look: a speed change that moves pixels must be indistinguishable to the eye in side-by-side stills at the scene's busiest and quietest frames, is owner-approved, and is reverted when a still shows the difference. Find speed in how a look is drawn, never in drawing less of it.
- **Performance lives in the framework** (owner, 2026-09-27): a speed-up is made in `@bible/film` (engine, compositor, kit primitives, renderer, tools), so every film gets it, never by tuning or simplifying one film's scenes. A slow scene is a benchmark case that points at the framework primitive to fix; a finding whose fix is a scene edit is rejected on **Performant**, or re-framed as the primitive that scene exposes.
- Adopt a pattern from prior art only when it keeps every north star. Record which north star each rejected pattern fails.
