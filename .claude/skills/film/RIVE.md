# Rive rigs

A body that moves (a figure, a creature, a jointed prop) is a Rive rig: bones, skinned paths, constraints and a view model, generated from TypeScript, built to a `.riv` by the Rive CLI, and posed by our frame. Rive draws the picture; the clock, the narration, the cues and the probes stay ours. The contract is `packages/film/README.md` § Rive; this file is the map, the rules no type confesses, and the proof.

## Declare and pose

- **A spec per engine.** `accusedProp(engine)` in `apps/animations/src/films/cold-studies/looks/rive/rigs.ts` is the shape: the `.riv` imported `with { type: 'file' }`, the artboard, the timelines and view-model numbers a pose may name (typed by the file's own `ACCUSED_TIMELINES` and `ACCUSED_KNOBS`, `figures.ts`), the engine, `key` (its name in errors), `origin` (the artboard point at our 0, 0) and `face` (the node `check` reads as the face).
- **A spec names its concept.** `concept: { image: { set, file } | { board }, box }` on a figure's spec is the picture the figure was painted from and its box there (the RBF figures, `apps/animations/src/films/righteousness-by-faith/rigs/rigs.ts`); `bun run match --film <film> --scene <id> --at mark:<m>` then holds the drawn figure to it: its proportions, its outline, its feet, ink and a light rim inside an inner part, its shading ([SKILL.md](SKILL.md), Easel). A rig with no concept is named unmatched.
- **A spec follows the shot.** `ink: (scale) => number` on a spec sets the view model's number `ink` (`INK_NUMBER`) each frame from the shot's scale (frame heights per artboard unit), before the pose's numbers. A figures file hands its rigs the house's rule as `FIGURES.shot` (`inkAt`: the line as cut while a head fills a fifth of the frame or less, 0.75 from three tenths, eased between); a file that bakes its ink hands none, and a spec with `ink` on a rig with no number `ink` fails the load. The shot is read in the space the rig stands in, before the pose's `size`: draw a figure's hand at its figure's scale with the hand's own size as `size` (`f.rive('hand', { timelines, size })`), never folded into the place's scale, or the hand thins before its figure in a push-in.
- **The look declares it; the scene passes it on.** The look sets `rigs: { accused: accusedProp('canvas') }`; the court's drawing writes `rigs: lookOf().rigs`, so the film loads exactly what the look in play draws. A look that draws its figure itself leaves the name out.
- **The draw poses it from `f`.** `f.rive('accused', poseOf(f))`: each timeline `[name, seconds, mix?]`, applied in order, then the numbers by name. Seconds come from the cues: `cueTime` stretches a timeline's authored move over its cue's `dur`, so a lab edit to the cue reshapes the move. A misspelt rig, timeline or number fails typecheck; a name the `.riv` lacks fails the load (`RigNameMissing`, listing what the file has).

## Purity: a fresh instance every frame

`drawRig` makes, every frame, an artboard instance from the loaded file, a view-model instance, and an instance of each timeline the pose names; it applies them, advances by no time, draws, and deletes them all. A frame is a function of its pose by construction. Keep it so:

- **Write the pose from `f` alone.** A module scratch object is fine when the pose rewrites it each frame (`NUMBERS` in `accused.ts`); a pose, artboard or instance kept for the next frame is not.
- **No rest pass and no reset timeline.** Posing one instance again keeps what earlier frames left in it: Rive remakes a shape's paths only when they move past a tolerance, so they keep an earlier frame's rounding; a constraint solves from the last frame's bones; a bind writes back into the view model. The design that posed one instance from rest through an authored `fresh` timeline had 60 of 60 frames off; reusing an instance drew 22 of 60 fixture frames and 59 of 60 accused frames off.
- **No state machine.** It keeps its state and any transition in flight between frames, and Rive would own time. The binds apply on the artboard's own `advance(0)`.
- **The draw path stays synchronous:** no Effect, no Promise, no try/finally. A frame that throws leaves its instances in the rig's in-flight slot; the next frame or the load's scope frees them.

The fresh instance has a cost (89 µs a frame for the accused in Bun). A speed-up keeps it and finds its time elsewhere ([performance.md](../film-architecture-loop/performance.md), Where time goes).

## Loads are scoped Effects

- **The layers.** `src/rive/` imports `core` and `canvas` only; the player (`narratedFilms`) and the tools (`check --draw`) import it, and the engine never does, apart from its fixtures, which load a rig to draw it. `.oxlintrc.json` holds both directions (`packages/film/README.md` § The purity rule). The house look, `src/style/`, imports `core` and `canvas` only, never `src/rive/`; a film reads it through `@bible/film/style` and `@bible/film/style/build`, never its rig (`src/style/rig/`): a film lays its figures in one file, which the house prints, and writes no RML; `core`, `canvas` and `src/rive/` never import it. A look reaches a rig only through `@bible/film/rive`: no package export resolves into `src/rive/`, and `.oxlintrc.json` refuses a relative path into `packages/film/src/` from `apps/animations/src/` (other app files are not checked yet).
- `loadRigs(film)` needs `RiveRuntime` and a `Scope`. `narratedFilms` makes each film's load an `Effect<Film, FilmUnloadable, Scope>`, and whoever runs it owns the scope and closes it: the player page (`stageFilm`, the page's own scope) and `check --draw` over `RiveRuntimeBun`.
- Run a load on the consumer's own fiber, inside its scope. Each wasm object a rig holds (the file, its renderers, its GL targets) belongs to that scope, so a rig handed out past a Promise (`Effect.runPromise` then a later use) is a use after free, and a top-level `await` of a runtime or a `.riv` holds a native lifetime no scope owns.
- Bun draws nothing (`paints: false`): the rig is posed for real and its face declared, so `check --draw` sees a throw, a pose naming what the rig lacks, and ink over a rig's face. A rig's pixels are proved only in a page (below).

## Engines and the GL budget

- A `webgl2` rig draws on a 512 px tile where its box fits, else a frame-sized target, primed once with the rig at rest before its first real frame (the engine's own, so the Rive Renderer's buffers are never sized by earlier frames), then composited with `drawImage`.
- Its targets share `glCanvas`'s budget of 8 live WebGL contexts (`holdGl`). A target whose context is lost (the budget let it go, or the browser) is remade and primed before it draws; where no WebGL 2 context can be made, the draw fails naming why, never a blank frame.
- `canvas` draws with Rive's Canvas 2D renderer on our own context. Where WebGL has no pixel local storage (SwiftShader), the Rive Renderer falls back to 4× MSAA and feathers only a `clockwise` fill.

## Build a rig

- The rig is code: a film lays its figures in one file (RBF's `figures.ts` `FIGURES`, laid by `style/figures-file.ts` `figuresFile`: its figures composed of the house's parts), and the house prints it (`figuresRml`: each figure drawn by `style/rig/draw.ts` `drawFigure`, in the house's line, `style/house.ts` `DIRECTION`, at the file's weight, through `style/rig/rml.ts` `el`, `fragment`). `bun apps/animations/src/films/righteousness-by-faith/rigs/build.ts` writes `project/` beside it (`rive.yaml` and the `.rml`, git-ignored), compiles it with the generator's `style/build.ts` `compile` (`rive <project> --once --quiet --format=json`, offline and unsigned), and copies the built `figures.riv` beside the rigs, where `rigs.ts` imports it, with its stamp (`figures.stamp.json`: the digests of the project and of the file, and the CLI's version). Before it compiles, the build holds each override on a figure to the owner's word on that figure (`style/build.ts` `unsaid`: a decision on his production's ledger filed at the point `item:<item>`, after the lock it frees, whose words are its quote, verbatim, or which filed the pick its answer cites; a question or a note is never his word) and each figure he locked to its lock, the lock to the decision it names (`unlocked`). It stops at an override in words he never said, in his words on another matter or citing a pick he never made, and at a print that is not the one its lock file holds unless an override so backed frees that print. The hash is the lock file's alone, so a review reads every change to one. A build whose stamp still holds (`style/build.ts` `unbuilt`) compiles nothing; to build with a newer CLI, delete the stamp first. Commit the rigs, the `.riv` and its stamp together: the film's test (`apps/animations/src/films/righteousness-by-faith/rigs/build.test.ts`) fails a `.riv` that is not the build of its rigs, an override no decision of the owner's on its figure backs, and a locked figure whose print is not his lock file's, with no CLI.
- The court's `figures.riv` (`cold-studies`) is frozen: no source builds it, and the numbers its poses read (`ACCUSED_KNOBS`, `JUDGE_TIMELINES`) are kept beside it in `figures.ts`, changed only with the file.
- The fixtures: `cd packages/film/src/rive/fixtures/arm && rive . --once`, and the same in `packages/film/src/rive/fixtures/ink` (a stroke's width bound through a `DataConverterRangeMapper`).
- **The ink binds through a range mapper.** Each ink stroke's `thickness` (property key 47) binds the number `ink` through its own `DataConverterRangeMapper` (`minInput` 0, `maxInput` 1, `minOutput` the width the paper and the light core cover, `maxOutput` the width as cut; write all four, each defaults to 1), unclamped, so the runtime maps it linearly. The CLI's `--screenshot` binds no view-model instance (`--data` says no view model is bound), so it draws a bind's authored value: prove a bind in the runtime (`rive.test.ts`) or the lab's `look`, never the CLI's screenshot.
- The CLI is `rive` on the PATH (this Mac: the Homebrew cask `rive-app/tap/rive-cli`, 1.5.1), or the one `RIVE` names for `build.ts`.
- A `.riv` is served as a file import (`assets.d.ts`): a page build bundles it and the page reads its URL through `HttpClient`; the wedge (`tools/wedge.ts`) bundles the render page with `publicPath: '/'`, so `render --level` and `check --level` serve it too; in Bun, and in the wedge's own module (`tools/wedge-module.ts`), it is a path on disk.

## CLI and runtime quirks

- **`rive inspect` exits 1 when the project has an error, and still prints the whole JSON report.** Decode stdout whatever the exit code; warnings alone exit 0.
- **Every `.rml` is a fragment:** `<Rive version="1" kind="fragment">…</Rive>` (`style/rig/rml.ts` `fragment`). Without it the build fails `missing <Rive> root`, and `inspect` adds `missing-backboard`; the wrapper fixes both.
- **A timeline instance has no length.** In the 2.43.1 runtime, `LinearAnimationInstance` has no `duration` or `fps`, though its types declare them. The pose computes time from each timeline's seconds, stated beside the rig: the court's in its `figures.ts` (`ACCUSED_TIMELINES`); a composed figure's breath lasts its stance's period (`stance.breath.period`, which the house prints as the breath's length) and its boil is the house's (`boilTime`), the timelines' names the house's (`FIGURE_TIMELINES`, `@bible/film/style`). An artboard's size is its `bounds`.
- **The WebGL 2 runtime has no `beginFrame`,** though its types say so: `clear` starts the frame (`canvas/rive.ts`).
- **WebGL 2 is SwiftShader's on every host.** Bun spawns Chrome with `--disable-gpu`, which no later flag undoes; on macOS the renderer's Chrome is spawned through the GPU launcher (`tools/chrome-gpu.ts`), which drops it so the GPU process holds the hardware encoder, and `launchArgs` (`tools/browser.ts`) keeps its WebGL on SwiftShader (`--use-angle=swiftshader`), not the Mac's GPU. So a Mac render, a Linux render, the lab's `look` and the browser tests (`lab/fixtures/browsers.ts`) draw a `webgl2` rig and a `glCanvas` look on one renderer, at about 19 ms a `webgl2` figure.

## Prove a change

From `packages/film`:

```sh
bun test src/rive src/tools/draw-check.test.ts src/player/narrated.test.ts src/canvas/gl.test.ts
lockf -k /tmp/bible-tools-e2e.lock bun src/lab/fixtures/run-suite.ts e2e/canvas/rive.pixel.test.ts   # flock on Linux
```

- `src/rive/rive.test.ts` proves purity path for path (60 shuffled frames against a newly loaded rig), and that a load stopped, failed or closed mid-way frees everything; `e2e/canvas/rive.pixel.test.ts` proves it in pixels (five times after two histories, against a fresh page) and past a lost context.
- A rig on a real look, in-process: from `apps/animations`, `bun run check cold-studies --draw --level style=rive --scene court` (`style=rivegl` for the `webgl2` engine). A rig error is the finding; in a worktree with no mix, `AudioMissing` and two `EndShort` are the film's sound, not the rig.
- Then `bun run gate`.
